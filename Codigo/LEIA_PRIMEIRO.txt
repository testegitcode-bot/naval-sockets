BEM-VINDO!

Este é um jogo de Batalha Naval completo, desenvolvido em Java com interface
gráfica usando Swing. Está pronto para rodar em seu computador.

════════════════════════════════════════════════════════════════════════════

🚀 COMECE AQUI (3 MINUTOS)
════════════════════════════════════════════════════════════════════════════

1. CERTIFIQUE-SE QUE JAVA ESTÁ INSTALADO
   
   Abra terminal/prompt e digite:
     java -version
     javac -version
   
   Se não funcionar, instale Java em: https://www.oracle.com/java/

2. EXECUTE O SCRIPT

   Windows:
     Duplo clique em run.bat
     (ou digite: run.bat no terminal)
   
   Linux/macOS:
     Terminal: chmod +x run.sh && ./run.sh

3. APROVEITE O JOGO!
   - Clique no tabuleiro da direita para atacar
   - Vermelho = acerto (ataque novamente)
   - Branco = erro (passa o turno)
   - Primeiro a destruir 17 células vence!

🎮 COMO JOGAR
════════════════════════════════════════════════════════════════════════════

1. Janela abre com 2 tabuleiros lado a lado
2. Esquerda = SEU TABULEIRO (cinza com seus navios)
3. Direita = TABULEIRO INIMIGO (azul, para atacar)
4. CLIQUE em qualquer quadrado AZUL para atacar
5. Se acertar (vermelho): ataca novamente
6. Se errar (branco): passa a vez para o inimigo
7. Primeira a destruir 17 células de navios vence!

📊 ESTRUTURA DO PROJETO
════════════════════════════════════════════════════════════════════════════

BatalhaNavalLogic.java (Lógica)
├─ Matriz 10x10 para cada tabuleiro
├─ Posicionamento de navios (8 navios, 20 células)
├─ Sistema de turnos
├─ Verificação de acertos/erros
├─ IA aleatória
└─ Placeholders para Socket

BatalhaNavalGUI.java (Interface)
├─ Swing com JFrame e JPanel
├─ 200 botões (2 tabuleiros 10x10)
├─ Cores atualizadas em tempo real
├─ Indicador de turno
├─ Diálogos de vitória/derrota
└─ Menu para novo jogo
