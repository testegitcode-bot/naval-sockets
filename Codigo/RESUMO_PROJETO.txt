COMO EXECUTAR
═══════════════════════════════════════════════════════════════════════════

OPÇÃO 1: Script automático

  Linux/macOS:
    ./run.sh

  Windows:
    run.bat


OPÇÃO 2: Compilar e executar manualmente

  1. Compilar:
     javac BatalhaNavalLogic.java BatalhaNavalGUI.java

  2. Executar:
     java BatalhaNavalGUI

CORES UTILIZADAS
═══════════════════════════════════════════════════════════════════════════

🔵 AZUL (65, 105, 225) - Água / Célula não atacada
🟩 CINZA (128, 128, 128) - Navio / Seu tabuleiro
🔴 VERMELHO (220, 20, 60) - Acerto
⚪ BRANCO (255, 255, 255) - Erro


ESTRUTURA DE DADOS
═══════════════════════════════════════════════════════════════════════════

Cada tabuleiro é uma matriz 10x10 de inteiros:

  0 = AGUA      (azul, não foi atacado)
  1 = NAVIO     (cinza, navio posicionado)
  2 = ACERTO    (vermelho, acertou um navio)
  3 = ERRO      (branco, atacou água)


NAVIOS NO JOGO
═══════════════════════════════════════════════════════════════════════════

Tamanho 4: 1 navio   (4 células)
Tamanho 3: 2 navios  (6 células)
Tamanho 2: 3 navios  (6 células)
Tamanho 1: 4 navios  (4 células)
───────────────────────────────
Total:     8 navios  (20 células)

Vitória: Destruir 17 células (os 3 últimos pontos têm mais dificuldade)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ Erro: "javac: command not found"
   → Java não está instalado
   → Veja INSTRUCOES_EXECUCAO.md para instalar

❌ Erro: "Exception in thread 'main'"
   → Verifique se os arquivos estão na mesma pasta
   → Recompile com: javac *.java

❌ A janela não abre
   → Verifique se tem interface gráfica disponível
   → Teste em uma máquina com GUI
